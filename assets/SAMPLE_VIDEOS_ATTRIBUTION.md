| File | Label | Source | Duration | Format |
|------|--------|--------|----------|--------|

2. Update this file with source, license, and citation.
3. Update the clip descriptions in `client/demos/app/demos/demo/page.tsx` and the **Demo** bullet in the root `README.md` so the UI and docs match.
4. Rebuild or redeploy the UI if your runtime image embeds `assets/` at build time.
